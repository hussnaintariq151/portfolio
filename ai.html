// 02. AI engineering

ML, deep learning &
Generative AI in production.

I build ML, deep learning, and Generative AI systems end to end — from data pipelines and evaluation through to RAG chatbots, agents, and MCP servers that actually ship. The hard part isn’t a demo; it’s a system that behaves.

01.How I work

Generative AI & RAG

Retrieval-augmented assistants and agents with grounded answers — LangChain, LangGraph, vector search, and MCP servers.

Deep learning

Model design, training, and fine-tuning with PyTorch and Keras — from computer vision to sequence models on real datasets.

Classical ML

scikit-learn pipelines for tabular problems, with honest baselines, careful feature engineering, and proper validation.

Evaluation first

Before scaling anything, a real evaluation set and metrics — so “it feels better” becomes a number you can trust.

MLOps

Model registry, versioning, and monitoring for drift and cost — treating a model like software that has to stay healthy over time.

Serving & APIs

FastAPI wrappers around models, containerised for AWS or Azure, with the observability to catch problems before users do.
